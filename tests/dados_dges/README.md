# Páginas da DGES para os testes

Cópia de 165 páginas do *Guia da Candidatura 2026* da DGES (144 páginas de curso em `cursos/` e 21 índices em `indices/`), recolhidas a 23/10/2026 por `dados/recolher_dges.py` (US04).

Estão no Git porque os testes da US33 (`tests/test_us04_catalogo_completo.py`, `CondicoesDeAcessoTests`) confirmam que as condições de acesso lidas destas páginas são as do catálogo (`dados/catalogo-cursos.csv`). Não se atualizam com a recolha: as páginas da recolha completa ficam em `dados/dges_html/`, fora do Git (decisão da equipa, 03/11; ponto 3 de `docs/US04/requisitos.md`).
